# JustBoss ⚔️

A 2D side-scrolling, 1-on-1 boss fight game

---

## ⚙️ Tech Stack

* **C++**
* **SFML** (Simple and Fast Multimedia Library) for graphics and windowing.
* **ImGui** for in-game debugging tools.

---

## ▶️ How to Play

To start the game, run the executable file located at:

Build/bin/release/JustBoss.exe

---

## ⌨️ Controls

* **A**: **Dash**
    * Has a 5-second cooldown.
    * Can be used to cancel other attack animations.
* **S**: **Attack**
    * Your primary attack skill.
* **D**: **Jump**
* **D (while in the air)**: **Double Jump**
* **Q**: **Charge Attack**
    * A powerful, charged-up attack.
* **W**: **Weak Attack (Counter)**
    * When the boss glows, hitting it with this attack will put it into a **Groggy** state. While groggy, the boss takes double damage.
